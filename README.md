# rag-docs-bot

Бот, який відповідає на запитання по базі документів і до кожного твердження вказує пункт, на який спирається. Демо-корпус: Правила дорожнього руху України (редакція від 09.04.2026, zakon.rada.gov.ua). Замість ПДР можна покласти будь-які свої .md, .txt або .pdf.

Навчальний проєкт: мета була зібрати RAG своїми руками (нарізка, ембедінги, гібридний пошук, оцінка якості) і поверх нього агентний шар на Pydantic AI + Claude. Не продакшн.

## Приклад

```
$ python -m ragbot.cli "Чи можна обганяти на пішохідному переході і яка максимальна швидкість у житловій зоні?"

Ні, обгін біля пішохідного переходу заборонений, а в житловій зоні швидкість не більше 20 км/год.

- Обгін заборонено «ближче ніж за 50 м перед пішохідним переходом у населеному пункті
  і 100 м поза населеним пунктом» (п. 14.6 «в»). Також обгін заборонено на перехресті,
  на залізничних переїздах і ближче ніж за 100 м перед ними, у кінці підйому, на мостах,
  у тунелях (п. 14.6).
- «У житлових і пішохідних зонах швидкість руху не повинна перевищувати 20 км/год» (п. 12.5).
  Для порівняння: у населених пунктах не більше 50 км/год (п. 12.4).

Джерела, які бачила модель: п. 12.4, п. 12.5, п. 12.9, п. 14.6, п. 15.10, п. 18.3, п. 18.6, ...
· claude-opus-5 · пошуків: 2 · токени вхід 4871 / вихід 462 · ~$0.0359
```

Питання поза документами («Який штраф за перевищення швидкості?») бот не вигадує, а каже, що в документах цього немає: штрафи живуть у КУпАП, а не в ПДР.

## Як це працює

```
data/docs/*.md|txt|pdf
      │  chunking.py: заголовки задають шлях чанка, кожен пункт «п. 12.4» окремий чанк
      ▼
   чанки ──► embeddings.py (fastembed, локально, 384-вимірні вектори)
      │  ──► BM25 по токенах (rank-bm25)
      ▼
   store.py: SQLite, вектори як BLOB, пошук повним перебором у numpy
      │
      ▼
   retriever.py: вектори + BM25 → Reciprocal Rank Fusion → top-k
      │
      ▼
   agent.py: Pydantic AI Agent з інструментом search_docs
             модель сама вирішує, що і скільки разів шукати (агентний RAG),
             відповідає лише за знайденим і цитує пункти
      │
      ▼
   cli.py / bot.py (aiogram)
```

Ключова відмінність від «наївного RAG»: пошук не робиться один раз до виклику моделі. Модель отримує інструмент і може переформулювати запит, якщо перший пошук не дав відповіді. У прикладі вище вона зробила два пошуки, по одному на кожну частину питання.

## Якість

Еталон: 21 питання з ручною розміткою (номер пункту ПДР і обов'язкові фрагменти відповіді), з них 20 з відповіддю в документах і 1 поза документами. Один прогін 02.09.2026, `python -m eval.run_eval`. Повний звіт з промахами: [eval/results.md](eval/results.md).

Пошук, чи є потрібний пункт у топ-5 (20 питань):

| режим | hit@5 | MRR |
|---|---|---|
| лише вектори | 15/20 | 0.71 |
| лише BM25 | 18/20 | 0.82 |
| гібрид (RRF) | 19/20 | 0.85 |

Чому гібрид: маленька мультимовна модель ембедінгів (220 МБ) плутає близькі за змістом пункти, а BM25 точно ловить числа і терміни, зате не знає синонімів. Промахи в них різні, тому злиття рангів закриває більшість дір. Один промах гібриду лишився: питання про обгін на переході тягне пункти про пішоходів, а не п. 14.6 про обгін.

Відповіді моделі: результати прогону з `--answers` (обов'язкові фрагменти + посилання на потрібний пункт) у тому ж [eval/results.md](eval/results.md), разом з вартістю кожного питання.

Обмеження, які варто знати:

- 21 питання це мало для впевнених відсотків. Це перевірка «не зламано» і порівняння режимів між собою, а не оцінка для продакшену.
- Питання складав той самий автор, що й систему. Сторонній набір питань буде жорсткішим.
- Модель ембедінгів обрана за розміром, не за якістю. multilingual-e5-large (2.2 ГБ) майже напевно підняла б векторний hit@5, але вбила б «клонував і запустив».

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows; на Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env            # вписати ANTHROPIC_API_KEY або OPENROUTER_API_KEY
```

Ключ: якщо задано `ANTHROPIC_API_KEY`, запити йдуть напряму в Anthropic; якщо лише `OPENROUTER_API_KEY`, та сама модель через OpenRouter. Модель за замовчуванням `claude-opus-5`, у `.env` можна поставити `claude-sonnet-5` (приблизно у 2.5 раза дешевше за прайсом обох провайдерів).

Демо-корпус ПДР:

```bash
curl -L -A "Mozilla/5.0" -o data/raw/pdr.html "https://zakon.rada.gov.ua/laws/show/1306-2001-%D0%BF/print"
python ragbot/parse_pdr.py        # HTML → data/docs/pdr/*.md, один файл на розділ
python -m ragbot.ingest           # чанки → ембедінги → data/index.sqlite (перший раз скачує модель, 220 МБ)
```

Питання:

```bash
python -m ragbot.cli "З якого віку можна їздити на велосипеді по дорозі?"
python -m ragbot.cli                        # діалог з пам'яттю попередніх ходів
python -m ragbot.cli --search "обгін"       # лише пошук, без моделі і без витрат
```

Telegram: вписати `BOT_TOKEN` у `.env` і `python -m ragbot.bot`. Команда `/reset` чистить історію чату.

Оцінка: `python -m eval.run_eval` (пошук, безкоштовно) або `python -m eval.run_eval --answers` (плюс відповіді моделі, платно). Тести: `pytest`.

## Свої документи

Покласти файли в `data/docs/` (можна в підпапки) і виконати `python -m ragbot.ingest`. Для Markdown заголовки `#`, `##`, `###` стають шляхом чанка; підзаголовок виду `### п. 12.4` робить пункт окремим чанком з номером у посиланні. Для .txt і .pdf абзаци групуються приблизно по 900 символів.
